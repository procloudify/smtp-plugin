Dedicated high-speed SMTP mail routing plugin exclusively for Procloudify clients.

== Description ==

Procloudify SMTP ensures 100% email deliverability for your WordPress website by routing all outgoing emails through Procloudify's high-speed BDIX and Global mail servers.

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory, or install the ZIP through the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to **Procloudify SMTP** in your WordPress admin menu.
4. Enter your email and password, choose your server, and save.
5. Use the **Test Email** tab to verify connection.
